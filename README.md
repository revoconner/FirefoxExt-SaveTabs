# Firefox Extension - Save open tabs

**A save tab extension for firefox with the features as listed below:**

<img width="800" height="auto" alt="image" src="https://github.com/user-attachments/assets/85524d96-c24d-44db-93bf-95f80b6fcc4c" />

1. Save tabs from one open window, or tabs from all open window.
2. Rename the saved tabs
3. Open one of the tab or all at once
    - When opening tabs saved from multiple open windows, they open in different windows the way they were when saved.
    - they don't preload to save you from possible bot like action bot.
4. Export saved tabs as a txt file, or to clipboard.
5. Export all tabs saved at different times as json or import a previously saved json from backup. Useful during a new browser setup or migration.
6. When saving tabs into the same parent, option to replace or add new tabs.
7. hide page title in link row option will give the saved tabs a cleaner look by hiding titles.
